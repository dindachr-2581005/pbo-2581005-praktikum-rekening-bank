# Program Rekening Bank Mini

## Deskripsi
Program Rekening Bank Mini merupakan tugas Pemrograman Berorientasi Objek (PBO) yang dibuat menggunakan bahasa Java.

Program ini menerapkan konsep class, object, constructor, encapsulation, dan method.

## Class yang Digunakan

1. **Rekening.java**
    - Menyimpan nomor rekening, nama pemilik, dan saldo.
    - Memiliki method setor(), tarik(), getSaldo(), dan cetakInfo().
    - Menggunakan private untuk melindungi data rekening.

2. **BankMini.java**
    - Membuat object Rekening.
    - Menampilkan menu setor, tarik, info, dan keluar.
    - Menjalankan program melalui method main().

## Fitur Program
- Setor uang ke rekening.
- Tarik uang dari rekening.
- Menampilkan informasi rekening.
- Menolak transaksi dengan jumlah tidak valid.
- Menampilkan saldo akhir.

## Data Awal
- Nomor rekening: 001
- Nama pemilik: Ani
- Saldo awal: Rp100.000

## Cara Menjalankan
1. Buka project menggunakan IntelliJ IDEA.
2. Jalankan file BankMini.java.
3. Pilih menu sesuai kebutuhan.
4. Masukkan jumlah uang ketika diminta.
5. Pilih 0 untuk keluar dari program.
